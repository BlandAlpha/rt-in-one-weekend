# RTOW: 个人笔记站

## 这是什么

**如果你不是我，你不该看到这行字**。这是《一周末光线追踪》的笔记 + 代码誊抄。

我可以向你保证本代码库没有任何 AI 生成的代码，也没有任何 shadow 建议，只有一个 vscode，自动补全插件，和一双勤劳的双手。

如果你想看书，这里可以在线看原作：

[Ray Tracing In One Weekend - Peter Shirley, Trevor David Black, Steve Hollasch](https://raytracing.github.io/books/RayTracingInOneWeekend.html)

如果你觉得英文太难看，去拉他的仓库然后给agent说“翻译成中文”就ok了。

## 快速启动

没啥好上手的，如果你要运行的话直接执行 `run.sh` 就好，因为我在mac上编写的，所以windows的朋友们自己想办法咯，或者看看原作教程，第一章就是。

如果你是linux用户，那你应该具备足够的阅读本仓库的能力。

## 仓库架构

### 代码

非常扁平没啥好说的，纯粹的 `cpp` 代码。
